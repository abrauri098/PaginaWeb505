LISTAS DE DEFINICIÓNES

HTML
Lenguaje de marcado utilizado para estructurar el contenido de la web.
CSS
Lenguaje de estilos que define la apariencia visual de una página.
JavaScript
Lenguaje de programación que permite agregar interactividad a la web.
Etiqueta
Elemento del lenguaje HTML delimitado por corchetes angulares.
Atributo
Información adicional que se añade a una etiqueta HTML.
Navegador
Programa que interpreta el código HTML y muestra la página al usuario.
Servidor
Computadora que almacena y entrega los recursos web al cliente.
URL
Dirección única que identifica un recurso en Internet.
DOM
Modelo de objetos del documento que representa la estructura de la página.
Responsive
Diseño que se adapta a diferentes tamaños de pantalla y dispositivos.
