ETIQUETAS SEMÁNTICAS


REGRESAR

header

Sirve para agrupar el encabezado de la página: título, logo o eslogan.

nav

Sirve para agrupar los enlaces de navegación principales del sitio.

main

Sirve para envolver el contenido principal. Solo hay uno por página.

section

Sirve para agrupar contenido relacionado bajo un mismo tema.

article

Sirve para contenido independiente como noticias o posts.

aside

Sirve para contenido complementario o lateral no esencial.

search

Sirve para agrupar un formulario de búsqueda dentro del sitio.

address

Sirve para mostrar información de contacto del autor o del sitio.

footer

Sirve para cerrar la página con copyright o enlaces legales.
